# 🔐 Password Strength Analyzer

A Python-based cybersecurity tool that analyzes password strength,
detects common and insecure patterns, estimates entropy, checks
password breach exposure, and generates cryptographically secure
passwords.

## Features

✓ Password strength analysis
✓ 7-point scoring system
✓ Entropy estimation
✓ Effective entropy calculation
✓ Common password detection
✓ Sequential pattern detection
✓ Repeated-character detection
✓ Keyboard-pattern detection
✓ Password breach checking
✓ Risk-level assessment
✓ Security recommendations
✓ Cryptographically secure password generation
✓ Tkinter GUI
✓ Automated test suite
✓ Windows executable

## Technologies

Python 3.13
Tkinter
Pillow
PyInstaller
SHA-1
Have I Been Pwned API
secrets
